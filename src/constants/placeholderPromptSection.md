## Placeholder Usage

When drafting any document, use bracketed placeholders in the exact format `[LABEL]` — uppercase, spaces allowed, no punctuation inside brackets.

Prefer placeholders from the registry below over inventing new ones. If a registry placeholder fits the blank, use its exact label so auto-fill and color-coding apply.

### Registry

**PARTIES (P):** [CLIENT NAME], [OPPOSING PARTY NAME], [OPPOSING COUNSEL], [TENANT NAME], [LANDLORD NAME], [GUARANTOR NAME], [DEPONENT NAME], [JUDGE NAME], [WITNESS NAME], [OATH COMMISSIONER]

**DATES (D):** [TODAY'S DATE], [LEASE START DATE], [LEASE END DATE], [RENT DUE DATE], [HEARING DATE], [DEADLINE DATE], [NOTICE DATE], [DATE OF BIRTH]

**FINANCIAL ($):** [RENT AMOUNT], [SERVICE CHARGE], [SECURITY DEPOSIT], [CAUTION FEE], [AGENCY FEE], [PENALTY RATE], [LEGAL FEES], [CLAIM AMOUNT]

**LOCATION (A):** [PROPERTY ADDRESS], [CLIENT ADDRESS], [REGISTERED OFFICE ADDRESS], [COURT ADDRESS]

**COURT (C):** [COURT NAME], [SUIT NUMBER], [MATTER TITLE], [JURISDICTION], [CAUSE OF ACTION], [RELIEF SOUGHT], [EXHIBIT REFERENCE]

**FIRM (F):** [FIRM NAME], [FIRM ADDRESS], [SOLICITOR NAME], [FIRM REG NUMBER]

If no registry placeholder fits a case-specific blank, create a custom one using the same `[UPPERCASE LABEL]` format — it will render as Free Text category.

Never fill in a placeholder value yourself. Always leave it as `[LABEL]` for the user to complete, even if the value is knowable from context.

Group placeholders logically — e.g. all party names near the top/preamble, financial terms together in the relevant clause, court/suit details in the caption block.
