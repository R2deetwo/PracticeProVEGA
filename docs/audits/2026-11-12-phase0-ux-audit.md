## Design-system verdict

**What exists.** Var-backed Tailwind scales with 12 user themes + 2 product skins; self-hosted 3-register type system; ui/ primitive layer (13 components, ~60 adopting files); registry-based overlay architecture mid-migration (92 entries, 12 live in ModalShell); unified toast pipeline; Z_TIERS; safe-area utilities; focus-trap/dialog semantics; three CI ratchets (gray=0 hard, ui-primitives 2295, rounded-xl 74->72) — all verified tight at HEAD.

**What works.** Theme mechanics (per-account persistence, FOUC boot script, skin cascade beats user themes on primary); ratchet discipline (baselines match live counts exactly); V7 targeted a11y/responsive fixes; Vega/Atrium accent separation with byte-identical Komplete default; lazy modal forms delivering the 43% payload cut.

**What is inconsistent.** Status colour lives entirely outside tokens (7 raw hues, theme-blind); two modal systems with different z-index for the same surface; two button/input idioms (ui vs dead toolkit) and two radius specs / four shadow systems / three title scales; micro-type (8-10px x1900+) with sub-AA contrast pairs; 21/35 forms without submit guards; 2295 raw elements vs ~60 primitive adopters; designated shared components (FinancialStatusBadge, ViewHeader) with zero adopters; z-index mostly magic numbers despite Z_TIERS.

**What needs consolidation.** (1) Finish the overlay migration, delete ModalManager/Modal, unify z on Z_TIERS; (2) introduce semantic status tokens and route every status map/badge/toast through them; (3) delete the dead shadcn toolkit layer + components.json — single control idiom from ui/; (4) adopt the dead canon components (ViewHeader, FinancialStatusBadge) screen-by-screen under the ratchet model; (5) fix the body-font cascade and enforce the type scale (ban text-[Npx]); (6) reconcile radius/shadow specs to the compiled truth and correct STYLE_GUIDE.md; (7) extend the three existing gates (hex/rgba, z-[NNNN], text sizes) instead of adding new ones. All consolidation stays within the ONE existing design system; per-product separation grows from the same skin-class token mechanism, never a parallel system.
