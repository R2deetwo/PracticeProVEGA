* **Dynamic Court Heading Margin Rules:** When a court process is selected or detected, fix the top margin. The court caption heading must sit cleanly at the top of the first page canvas rather than drifting low down onto the sheet.

    * Automatically synchronize and apply the exact same Court Heading metadata across both generated files.
    * Establish an **intelligent sequential numbering/linking protocol** that logically pairs and references the processes to one another within the document workspace.

## FILE 4: `src/services/jurisdictionResolver.ts` — Implementation Checklist
[ ] resolveCourtTier(promptContext, defaultStateOfPractice): CourtTier
- Keyword match: subject matter (land/tenancy → STATE_HIGH_COURT or RENT_TRIBUNAL;
labor/employment → NATIONAL_INDUSTRIAL_COURT; tax → TAX_APPEAL_TRIBUNAL;
customs/immigration/federal agency party → FEDERAL_HIGH_COURT; election → ELECTION_PETITION_TRIBUNAL)
- Party-type check: if a party is Federal Government/agency, prefer FEDERAL_HIGH_COURT per
s.251 Constitution exclusive jurisdiction list; flag as suggestion, not silent override.
- Fallback to user's defaultStateOfPractice -> STATE_HIGH_COURT if no stronger signal.
[ ] resolveCaption(tier, state, judicialDivision, suitNo?): CaptionTemplate
- Pull from CAPTION_TEMPLATES by court.captionTemplateId
- Interpolate variables; if SUIT_NO unknown at draft time, render placeholder
"SUIT NO: " (not blank) per litigation convention
[ ] resolveDocumentType(tier, requestedDocLabel): DocumentType
- Validate requested doc against court.availableDocumentTypeIds
- If mismatch (e.g. user asks for "Petition" at a Magistrate Court), do NOT silently
substitute — return a resolution warning for ALOA to surface as a single clarifying
chip ("Did you mean Complaint instead of Petition for this court?")
[ ] applyAttestationBlock(docType)
- If docType.requiresAttestationBlock: inject center-aligned block:
"BEFORE ME,\n\nCOMMISSIONER FOR OATHS"
text-align: center; margin-top: 24pt; no left indent.
[ ] applyCourtMarginRules(tier)
- Court caption block: top margin fixed at 0.5in (not default 1in), no leading blank
paragraphs before caption. Firm/corporate headings keep existing margin rules —
branch on headingType, not globally.
[ ] bundleLinkedProcesses(processIds[])
- Same SUIT_NO + caption metadata propagated to all documents in bundle
- Sequential internal reference: "MOTION_ON_NOTICE" auto-links to its
"AFFIDAVIT" via bundleId; affidavit paragraph 1 auto-references
"the Motion on Notice dated {DATE} filed herewith"

## FILE 6: `src/services/ruleResearchPipeline.ts` — Implementation Checklist
[ ] resolveApplicableRule(tier, state, topic): ResolvedRule
ORDER OF RESOLUTION (stop at first hit):
1. VERIFIED_RULES lookup (exact tier+state+topic match) -> sourceType VERIFIED_STATUTE, confidence HIGH
2. If no state-specific entry exists, check for a national STANDARD entry
(state: null) for that topic -> apply standard, flag "no state nuance on record"
3. If neither exists, trigger AI_RESEARCH_FALLBACK (below) -> sourceType AI_RESEARCHED
4. If research fallback also fails/low-confidence, apply STANDARD as safe default
and flag sourceType UNVERIFIED_INFERRED — never block generation, always disclose.

[ ] AI_RESEARCH_FALLBACK(tier, state, topic)
- Fire a scoped Gemini API call with grounding/search enabled (not general knowledge recall)
- System prompt constrains model to: (a) cite the specific rule/order/section,
(b) state confidence, (c) explicitly compare to national standard, (d) refuse to
invent a citation it cannot support — return UNVERIFIED_INFERRED instead of guessing
- Cache successful lookups into a researchedRulesCache Convex table keyed by
{tier, state, topic} with a humanReviewPending: true flag, so:
- Same query never re-researches on every draft (cost + latency control)
- A queue exists for periodic human legal review to promote cache entries
into VERIFIED_RULES once confirmed
- Cache TTL: 90 days, then re-verify (rules change; don't trust stale AI research forever)

[ ] justifyRuleApplication(resolvedRule): JustificationChip
- Every time a nuance is applied that changes document structure, ALOA surfaces
a single inline chip in the chat panel, not buried in the document:
"Applied Lagos frontloading rule (Order 3 Rule 2(1), HCCPR 2019) — witness
statements on oath included with this Writ. [View standard vs. this state]"
- If sourceType is AI_RESEARCHED or UNVERIFIED_INFERRED, chip must say so plainly:

- Never present AI_RESEARCHED or UNVERIFIED_INFERRED rules with the same visual

(e.g. badge color/border), not just a tooltip.

[ ] conflictDetection(tier, state, topic)
- If VERIFIED_RULES has a divergesFromStandard: true entry, and the draft is

"{State} deviates from the national standard on {topic} — proceeding with
