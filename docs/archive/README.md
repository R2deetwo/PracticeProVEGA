# Archive — Historical Documentation

Superseded proposals, one-off prompts, past audits, fix logs, and old strategy docs. **Nothing here is active source of truth** — read it for context/history only. Kept to preserve the project's progress record; do not treat any statement in this folder as a current rule.

| Folder | Contents |
|--------|----------|
| `audits/` | Past audit reports (codebase, launch-readiness, CRO audit, offline/index verifications) |
| `fix-logs/` | Historical fix narratives (ALOA fixes, admin dashboard migration, remaining-items tracker) |
| `prompts/` | One-off AI generation prompts (dashboard evolution, pricing, onboarding polish, dictation, handoffs) |
| `specs/` | Superseded feature/implementation specs (AI features, automation, DraftPro guide, landing page, pricing, resources page) |
| `strategy/` | Old business/strategy docs (pricing strategy, sales playbook, digitization model, white-paper drafts, blog/help-center starter content) |
| `misc/` | Everything else (e.g. stray uploaded PDFs) |

If a doc in here becomes relevant again, promote it out with `git mv`, update it, and re-index it in [`../README.md`](../README.md).
