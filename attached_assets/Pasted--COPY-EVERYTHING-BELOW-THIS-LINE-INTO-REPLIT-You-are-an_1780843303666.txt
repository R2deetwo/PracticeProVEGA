## ROOT CAUSE ANALYSIS (I've had the codebase audited — here are the confirmed bugs)

### ROOT CAUSE 1: Property delete DOUBLE-FIRES
**File: `src/hooks/useProperties.ts` → `handleDeleteProperty`**

The delete handler calls BOTH:
1. `deletePropertyCascadeMutation` (which hard-deletes from the database)
2. `actions.deleteItem` (the generic delete, which tries to delete the SAME record again)

Since the cascade mutation already deleted the record, the second generic delete call FAILS (record not found). The `DataProvider.tsx` optimistic update pattern then ROLLS BACK the UI change (removes the deletion from local state), making the property reappear — even though it was actually deleted from the database. On the next data refresh, the property is gone, but until then it looks like it "restored" itself.

### ROOT CAUSE 2: `updateItem` mutation has NO authentication — it silently fails
**File: `convex/myFunctions.ts` → `updateItem` (around line 1663)**

The `updateItem` mutation does NOT call `requireFirmUser` or any auth check. It also uses `v.any()` for the data parameter with no type validation. When the edit form submits, the mutation may fail due to:
- Invalid field names or types being passed (no validation with `v.any()`)
- The mutation converting `null` to `undefined` for field deletion, which can cause schema validation errors
- No firmId authorization check, so ownership validation is missing

### ROOT CAUSE 3: Stale `prevState` in optimistic updates
**File: `src/contexts/DataProvider.tsx`**

The `updateItem` and `deleteItem` functions capture `prevState = appState` at call time via closure, NOT at render time. If two rapid operations happen, the second rollback undoes the first operation's changes. This causes state desync.

### ROOT CAUSE 4: `deleteItem` Strategy A deletes wrong records
**File: `convex/myFunctions.ts` → `deleteItem` (around line 1713)**

The `deleteItem` mutation has a dangerous pattern:
```
try { ctx.db.delete(id) } catch(e) { /* fallback to UUID search */ }
```
This catches ALL errors, including permission errors. If a valid Convex ID from a DIFFERENT table is accidentally passed, it silently deletes that record instead. There is NO table validation and NO firmId check.

deleteItem: async (table, id) => {
  let removedItem: any = null;
  let removedIndex = -1;

  setAppState(prev => {
    const items = prev[table as keyof typeof prev] as any[];
    const idx = items.findIndex((item: any) => item._id === id || item.id === id);
    if (idx !== -1) {
      removedItem = items[idx];
      removedIndex = idx;
      const newItems = [...items];
      newItems.splice(idx, 1);
      return { ...prev, [table]: newItems };
    }
    return prev;
  });

  try {
    await deleteItemMutation({ table, id });
  } catch (error) {
    // Roll back by re-inserting the removed item at its original position
    if (removedItem && removedIndex !== -1) {
      setAppState(prev => {
        const items = [...(prev[table as keyof typeof prev] as any[])];
        items.splice(removedIndex, 0, removedItem);
        return { ...prev, [table]: items };
      });
    }
    toast.error(`Failed to delete ${table.slice(0, -1)}. Changes reverted.`);
  }
},

export const softDeleteItem = mutation({
  args: {
    table: v.string(),
    id: v.string(),
  },
  handler: async (ctx, args) => {
    const identity = await ctx.auth.getUserIdentity();
    if (!identity) throw new ConvexError("Not authenticated");

    // Only allow soft-delete on tables that support it
    if (!["properties", "contacts"].includes(args.table)) {
      throw new ConvexError(`Soft delete not supported for table: ${args.table}`);
    }

    let docId: Id<any>;
    try {
      docId = args.id as Id<any>;
    } catch {
      const doc = await ctx.db
        .query(args.table)
        .filter(q => q.eq(q.field("id"), args.id))
        .first();
      if (!doc) throw new ConvexError(`Document not found: ${args.id}`);
      docId = doc._id;
    }

    const existing = await ctx.db.get(docId);
    if (!existing) throw new ConvexError(`Document not found: ${args.id}`);

    // Verify ownership
    if (existing.firmId) {
      const user = await ctx.db
        .query("users")
        .filter(q => q.eq(q.field("clerkId"), identity.subject))
        .first();
      if (!user || user.firmId !== existing.firmId) {
        throw new ConvexError("Not authorized");

      deletedAt: Date.now(),

export const oneTimeCleanupProperties = mutation({
  args: { firmId: v.string() },
  handler: async (ctx, args) => {
    // Get all properties for this firm
    const properties = await ctx.db
      .query("properties")
      .withIndex("by_firm", q => q.eq("firmId", args.firmId))
      .collect();

    let deleted = 0;
    let repaired = 0;

    for (const prop of properties) {
      // Delete properties that have corrupted/missing required fields
      if (!prop.name || !prop.address || !prop.firmId) {
        await ctx.db.delete(prop._id);
        deleted++;

            serviceCharge: 0,
            cautionFee: 0,
            totalPackage: 0,
          },
        });

      if (prop.isDeleted === undefined) {
        await ctx.db.patch(prop._id, {
          isDeleted: false,
        });
      }
    }

    return { deleted, repaired, total: properties.length };
  },
});
