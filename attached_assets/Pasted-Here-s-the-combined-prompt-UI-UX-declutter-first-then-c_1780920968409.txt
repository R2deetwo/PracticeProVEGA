# ═══════════════════════════════════════════
# CRITICAL: VERCEL BUILD PREVENTION
# ═══════════════════════════════════════════

**⚠️ DO NOT regenerate `package-lock.json` using `npm install` inside Replit.** Replit's npm proxy bakes `http://package-firewall.replit.local/` into the lockfile, breaking Vercel builds.

**Prevention Rules**:
1. **Never run `npm install`** for adding packages. Manually add to `package.json` instead.
2. If you MUST run `npm install`, immediately run:
   ```bash
   sed -i 's|http://package-firewall.replit.local/npm/|https://registry.npmjs.org/|g' package-lock.json
   ```
3. Before any `git push`, verify:
   ```bash
   grep -c "package-firewall.replit.local" package-lock.json
   ```
   If count > 0, run the `sed` command.
