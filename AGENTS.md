## What this repository is

PracticePro — a Nigerian legal-tech platform, one monorepo, three surfaces:

| Surface | Path | What it is |
| --- | --- | --- |
| **Vega** | `src/` (Vega views), `/vega` site | Legal practice OS: matters, cause list, DraftPro, billing, trust ledger. ALOA is its AI. |
| **Atrium** | `src/` (Atrium views), `/atrium` site | Property/estate OS: rent roll, tenancies, service charge, maintenance. ARIA is its AI. |
| **Hub** | `src/sites/hub/` | Corporate site. **No AI assistant** — ALOA/ARIA are product features, not company ones. |

Stack: Vite SPA (React 18) + Convex backend (`convex/`) + Vercel + GitHub
Actions (tests → staging → production promote, pinned SHA). Admin portal and
Android APK build from the same tree.

## The five hard rules (never violate)

1. **Deterministic before generative.** Jurisdiction, limitation, notice
   periods, compliance checks and money are computed by typed, tested engines
   (`src/legal/`, `src/utils/tenancyNoticePeriods.ts`), never generated by an
   LLM. An LLM must never directly execute a state-changing action.
2. **No invented legal specifics.** Statutory figures only from encoded
   frameworks; everything else says so. Unverifiable citations surface as
   `UNVERIFIABLE`, never as confident prose (`src/legal/citations/`).
3. **Money is kobo integers** (`src/utils/` money helpers). Never floats.
4. **Security boundaries are server-enforced** — RBAC + state machines in
   Convex mutations (`convex/callerAuth.ts`), identity never trusted from the
   client, AI endpoints session-gated, API keys out of URLs (Round S2).
5. **Ratchets only move down.** `scripts/check-design-tokens.mjs` and
   `scripts/check-ui-primitives.mjs` hard-gate in CI; baselines never grow.

## Brand rules — PracticePro is the company; Vega and Atrium are the apps

The single source of truth is **`docs/brand-architecture.md`** — read it
before writing ANY user-visible name. The model, in one breath:

- **PracticePro Systems Limited** ("PracticePro") is the COMPANY — the
  builder. It is never the name of a product, and a product is never an
  alias of it.
- **PracticePro Vega** ("Vega", legal OS) and **PracticePro Atrium**
  ("Atrium", property OS) are the PRODUCTS. **Komplete** is the bundle.
  ALOA is Vega's assistant only; ARIA is Atrium's only.
- Product surfaces name the PRODUCT ("Why firms run on Vega"); the company
  answers "who builds it" ("Built by PracticePro"). Never invert this.
- APK artifacts follow `<product>-<version>-<channel>.apk` (universal build:
  `practicepro-…`; founder: `practicepro-founder-…`). Per-product wrapper
  builds share `applicationId` `com.practicepro.app` — never change it.
- The founder APK is NEVER a public release asset (public repo, public
  Releases page). Login-gated Actions artifacts only.
- Enforcement lives in `tests/unit/corporateIdentity.test.ts`,
  `tests/unit/websiteRepositioning.test.ts` and
  `tests/unit/brandClarity.test.ts` — add pins, never weaken them.

## Operating discipline (60/30/10)

- **60% mechanical plumbing** — move files, parse paths, shell out.
- **30% deterministic code** — typed tables, validators, Convex queries.
- **10% LLM reasoning** — synthesis, translation, drafting. Context per
  stage stays small (2k–8k tokens); every intermediate output is an
  editable Markdown/JSON file, never a black box.
